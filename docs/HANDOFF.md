## ۳. این سه کار را نکن

1. **پول را `number` نکن.** همه‌چیز `Decimal` است. یک `Number()` در مسیر پول،
   گزارش سود را برای همیشه خراب می‌کند.
2. **قاعدهٔ «منع تماس» را فقط در UI نگذار.** در API هم اعمال می‌شود (`409`).
   اگر از سرویس دور بزنی، قانون نقض می‌شود.
3. **عدد جادویی در سرویس ننویس.** وزن‌ها و آستانه‌ها در `Setting` هستند.
   اگر سخت‌کد کنی، پنل تنظیمات بی‌اثر می‌شود و کسی نمی‌فهمد چرا.

## ۴. پنج تله‌ای که با خون دل پیدا شدند

اینها را دوباره کشف نکن:

| تله | نشانه | راه‌حل |
|---|---|---|
| `electron-builder` پوشه‌های نقطه‌دار و `node_modules` را در `extraResources` **فیلتر می‌کند** | سرور بسته‌بندی‌شده `Cannot find module 'next'` می‌دهد | بسته‌بندی در `server.tar.gz` + استخراج در اولین اجرا |
| بک‌اسلش در رشتهٔ JS | `"C:\Windows\System32\tar.exe"` → `\t` تب می‌شود | مسیر را با `/` بنویس |
| بستن splash قبل از پنجرهٔ اصلی | اپ خودش را می‌بندد (بی‌صدا) | اول `createWindow`، بعد `splash.destroy()` |
| Node فایل `.ts` را اجرا می‌کند ولی import نسبی بدون پسوند را نه | `ERR_MODULE_NOT_FOUND` در seed | یا `.ts` بنویس (با `allowImportingTsExtensions`)، یا `decimal.js` را مستقیم import کن |
| `graphify query` با فارسی | `No matching nodes found` | شناسه‌های کد انگلیسی‌اند — با انگلیسی بپرس |

## ۵. سه قدم بعدی (به ترتیب اثر)

1. **صفحهٔ تنظیمات AI داخل برنامه** — الان کلید فقط از `.env` می‌آید. کاربر مغازه
   نباید با فایل سر و کله بزند. کلید را در `Setting` (رمزنگاری‌شده) ذخیره کن.
2. **تایم‌لاین معامله/مشتری** — تاریخچهٔ کامل تصمیم‌ها از `DecisionLog` و `Activity`.
3. **جست‌وجوی سراسری ⌘K** — دکمه‌اش در `app-shell.tsx` هست، عملکردش نه.

## ۷. قواعد تحویل

- بعد از **هر** تغییر: `npm run verify` → commit → push. هوک‌ها گراف را سینک می‌کنند.
- روی ماشین جدید: `npm run hooks:install` (یک‌بار).
- گزارش تحویل چهار خط است: چه شد / تست / قدم بعدی.
